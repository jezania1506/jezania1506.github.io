## Menjalankan Website Secara Lokal

Pastikan Node.js dan pnpm sudah terpasang pada komputer.

1. Clone repository:

   ```bash
   git clone https://github.com/jezania1506/jezania1506.github.io.git
   ```

2. Masuk ke folder proyek:

   ```bash
   cd jezania1506.github.io
   ```

3. Instal dependensi:

   ```bash
   pnpm install
   ```

4. Jalankan server pengembangan:

   ```bash
   pnpm dev
   ```

5. Buka alamat berikut pada browser:

   http://localhost:4321

Untuk membuat versi produksi, jalankan:

```bash
pnpm build
```
